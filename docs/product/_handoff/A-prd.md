# A · PRD 갱신 프롬프트

새 세션에 이 파일을 통째로 주고 실행시킨다.

---

## 배경

MediVU-community는 이미 코드 17,000줄과 제품 문서 7종을 가지고 있다. 문서는 2026-08-19에 쓰였고, 시장분석 보고서 4종이 08-22~23에 나오면서 **문서의 전제 몇 개가 뒤집혔다.** 2026-08-27에 그 충돌을 닫은 결정 기록이 `docs/product/05-decisions.md`이고, 그 결과로 새로 쓴 정보 구조가 `docs/product/15-information-architecture.md`다.

**당신이 할 일은 새 PRD를 쓰는 것이 아니라, 이미 있는 문서를 새 결정에 맞추는 것이다.**

## 먼저 읽을 것 — 순서대로

1. `docs/product/05-decisions.md` — **가장 중요.** 다른 문서와 충돌하면 이 문서가 맞다
2. `docs/product/15-information-architecture.md`
3. `docs/product/00-product-definition.md`
4. `docs/product/10-personas.md`
5. `docs/product/20-user-flows.md`
6. `docs/product/50-nonfunctional.md`
7. `src/App.tsx` (라우트), `src/domain/types.ts` (도메인 타입)

읽지 않아도 되는 것: `docs/시장분석/` 원본 보고서. 결론은 `05-decisions.md`에 이미 반영돼 있다.

## 산출물

## 필수 수정 — 빠뜨리면 실패

### 1. `00-product-definition.md`의 D-1 문장을 바꾼다

기존 (a)안이 이렇게 쓰여 있다: *"의원에게 새 환자를 데려오는 채널"*. **이 표현은 개정 의료법 제34조의9(선택 유도 금지)에 저촉된다.** 다음으로 바꾼다:

> 환자가 자기 증상을 볼 의사를 **스스로 찾는** 자리

주어가 플랫폼이 아니라 환자여야 한다. 문서 전체에서 "환자를 데려온다·유치한다·연결해 준다" 방향의 문장을 찾아 모두 고친다.

### 2. 원칙 4를 강화한다

기존: *"노출 우선권을 팔지 않는다. 사연은 최신순으로만 정렬한다."*
이건 필요조건이지 충분조건이 아니다. **돈을 받지 않아도 정렬이 선택을 유도하면 제34조의9에 걸린다.** `05-decisions.md`의 C-2와 그 파생규칙 4개를 원칙 4에 흡수한다.

### 3. 원칙 목록에 P-1을 추가한다

`05-decisions.md`의 P-1(이 도메인에서 힉의 법칙은 무조건 옳지 않다). 줄이는 것과 늘리는 것을 구분해 적는다.

### 4. 미검증 가설을 사실로 쓰지 않는다

`05-decisions.md`의 H-1~H-4는 근거가 없다. PRD 본문에서 단정형으로 쓰지 말고, "가설"로 표시하고 `05-decisions.md`를 참조시킨다. 특히 **"의사들이 답변에 몰릴 것"(H-2)은 인터뷰 0건 상태의 추측이다.**

## 지킬 것

- **기존 문서의 목소리를 유지한다.** 짧은 단정형, 표, "무엇을 하지 않는가" 목록. 새 스타일을 도입하지 않는다
- **결함 ID를 보존한다.** `F-*`(데이터), `R-*`(위험), `I-*`(조작감)는 다른 문서가 참조한다. 번호를 바꾸거나 지우지 않는다
- **코드에서 확인한 사실만 쓴다.** "지금 실제로 동작하는 것" 절은 파일을 열어 확인하고 쓴다. 추측으로 채우지 않는다
- **분량을 늘리지 않는다.** 결정이 줄었으면 문서도 줄어야 한다. P3 강등으로 지워지는 내용이 있다

## 하지 말 것

- `30-feature-spec.md`·`40-data-model.md`를 건드리지 말 것 — B·C 프롬프트의 담당이다
- 코드를 고치지 말 것. 이 세션은 문서만 다룬다
- `05-decisions.md`의 미결(Q-1~Q-4, D-6)을 임의로 정하지 말 것. **막히면 물어본다**
- 새 페르소나·새 기능·새 원칙을 발명하지 말 것

## 끝났다고 판단하는 기준

4. H-1~H-4가 단정형으로 쓰인 곳이 없다
5. 기존 `F-*`·`R-*`·`I-*` 번호가 전부 살아 있다
6. `git diff --stat`이 4개 파일만 보여 준다
