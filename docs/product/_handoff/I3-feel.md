새 세션에 이 파일을 통째로 주고 실행시킨다.

> **선행 조건** — I0의 M0-2(팔레트 커밋)만. I1·I2와 순서를 바꿔도 된다.
> **읽는 순서** — `docs/product/50-nonfunctional.md` §앱 조작감 P0 · `docs/product/adr/0001-pwa-vs-native-shell.md`

## 이 구간이 하는 일

*"앱 같지 않다"* 의 원인은 플랫폼이 아니라 **아직 안 쓴 CSS**다. ADR-0001이 그것을 추적했다 — 지적된 체감 8가지 중 7가지가 웹 레이어에서 해결된다. `src/styles.css`에 `@keyframes`가 **0개 / 3,846줄**이다.

**D-3이 Capacitor로 닫혔어도 이 작업은 낭비가 아니다.** 쉘을 씌워도 `@keyframes` 0개는 그대로다.

## 할 일 — I-1 ~ I-10

`50-nonfunctional.md` §P0에 열 개가 **줄 번호와 함께** 있다. 그대로 실행한다. 여기서는 순서와 함정만 적는다.

### 1. I-1 + I-10을 **같은 커밋**으로

| | |
| --- | --- |
| I-1 | `index.html:5`에 `viewport-fit=cover` |
| I-10 | `.segment-tabs { top: 66px }` → `calc(66px + env(safe-area-inset-top))` (`styles.css:1653`) |

**I-1만 넣으면 sticky 탭이 헤더 밑에서 어긋난다.** 그리고 I-1 한 줄이 **죽어 있던 `env(safe-area-inset-*)` 7곳을 되살린다**(`styles.css:186` `:282` `:345` `:346` `:3215` `:3378` `:3497`). 이 커밋의 효과가 가장 크다.

### 2. I-2 · I-3 — 팔레트 통일

- I-2: `vite.config.ts:17` `#0b2944`(네이비) vs `index.html:6` `#0d2b29`(청록)
- I-3: `vite.config.ts:18` `#edf2f6` vs `body` `#eef1f1`

**M0-2가 커밋한 팔레트 변경이 무엇을 정본으로 삼았는지 보고 그쪽으로 맞춘다.** 임의로 고르지 마라 — 커밋 기록이 답을 갖고 있다.

### 3. I-4 ~ I-9

전부 CSS 한 줄~몇 줄이다. `50-nonfunctional.md`에 줄 번호가 있다.

**I-7이 함정이다** — `overscroll-behavior-y`의 유일한 선언(`styles.css:3770`)이 `@media (min-width: 768px)` 안에 있어서 **실기기에서 안 걸린다.** 미디어쿼리 밖으로 꺼낸다.

**I-8도 함정이다** — 활성 탭 `font-weight: 700`은 애니메이션이 안 되고 라벨 폭이 리플로우돼 **탭마다 글자가 덜컹인다.** 색·인디케이터로 바꾼다. 같은 패턴이 `:253` `:311` `:372` `:383` 넷이다.

## 하지 말 것

- **화면 로직을 고치지 마라.** 이 구간은 CSS·`index.html`·`vite.config.ts`다
- I-11 이후(P1·P2)로 넘어가지 마라. 스켈레톤·토스트·View Transitions는 다음이다
- `styles.css`를 분할하지 마라 — **필요해지면 그때 한다.** 혼자이므로 미리 나눌 이유가 없다
- 새 색·새 토큰을 만들지 마라. 이미 모션 토큰(`styles.css:39-40`)과 `prefers-reduced-motion` 리셋(`:2785`)이 깔려 있다

## 확인

**실기기 설치 PWA에서 봐야 하는 것들이 있다.** 브라우저만으로는 safe-area가 확인되지 않는다.

| 어디서 | 무엇 |
| --- | --- |
| 브라우저 (375×812) | 탭 전환에 **글자가 덜컹이지 않는가**(I-8) · 탭 후 hover가 남지 않는가(I-9) |
| **실기기 설치 PWA** | 하단 내비가 제스처바를 피하는가 · 헤더가 상태바를 피하는가(I-1) · 당겨서 새로고침이 안 되는가(I-7) |
| 설치 화면 | 스플래시→앱 전환에 색이 튀지 않는가(I-3) · 타이틀바 색(I-2) |

**실기기 확인은 사용자가 한다.** 무엇을 봐야 하는지 목록으로 만들어 준다.

## 끝났다고 판단하는 기준

1. I-1 ~ I-10이 전부 반영됐다
2. **I-1과 I-10이 같은 커밋에 있다**
3. `theme_color`·`background_color`가 `vite.config.ts`와 `index.html`에서 같다
4. `overscroll-behavior-y`가 미디어쿼리 밖에 있다
5. 활성 탭에 `font-weight` 변경이 없다
6. `npm run test:run` 통과
7. 실기기 확인 목록을 사용자에게 전달했다
8. `50-nonfunctional.md`의 I-1~I-10을 **지운다** — 해결한 사람이 그 문서에서 지운다
