## 왜 이것이 관문인가

**G-2(탭 재편)는 G-1·G-3·G-4의 전제다.** 셋 다 탭이 먼저 바뀌어야 앉을 자리가 생기는데, **셋이 만지는 파일이 `BottomNav.tsx` 하나(58줄)** 다. 나중에 하면 같은 파일을 세 번 연다.

**이 세션이 라우트 표를 확정한다.** 끝나면 다음 구간들이 서로 다른 파일로 흩어진다.

## 할 일 — 한 커밋으로 묶어도 된다

| | |
| --- | --- |
| **G-2** | 하단 탭을 `홈 · 내 소식 · Q · 진료 · MY`로 (`BottomNav.tsx:10-16`) |
| 함께 | `/care` **빈 라우트** · 리다이렉트 3개 · **G-11**(`/me/payment` 삭제) |

### 탭

```
현재: 홈 · 사연 · Q · 지도 · MY
목표: 홈 · 내 소식 · Q · 진료 · MY
```

- `사연` 탭이 없어진다 — `/home`이 그 역할을 가져간다 (G-1은 다음 구간)
- `내 소식`(`/news`)이 헤더 종 아이콘에서 탭으로 올라온다. **`AppHeader.tsx:22-30`의 종 아이콘을 뺀다**
- `지도` → `진료`(`/care`)

### 라우트

| 라우트 | 할 일 |
| --- | --- |
| `/care` | **신설.** 빈 껍데기 + 「여기에 지도와 진료 이력이 들어옵니다」 수준 |
| `/map` | → `/care` 리다이렉트 |
| `/stories` | → `/home` 리다이렉트 |
| `/me/appointments` | → `/care` 리다이렉트 |
| `/me/payment` | **삭제** (G-11) — 라우트·화면·MY 목록의 링크까지 |

**빈 라우트를 함께 넣는 이유** — 탭만 바꾸면 `진료` 탭이 없는 주소를 가리켜 죽은 탭이 된다. **껍데기와 리다이렉트까지가 한 몫이다.**

**G-11이 여기 있는 이유는 같은 파일이다.** `/me/payment` 삭제는 `App.tsx`의 라우트를 지우는 일이고 이 세션이 이미 `App.tsx`를 열어 둔다. 근거는 `05-decisions.md` D-4 §따라온 것.

## 확인

**브라우저로 직접 본다.** `.claude/launch.json`에 `medivu-dev`가 있다. 띄우고 모바일 뷰포트(375×812)로 다섯 탭을 눌러 본다.

- 탭 다섯 개가 전부 살아 있는 주소를 가리키는가
- 리다이렉트 셋이 도는가
- `/me`에서 `결제수단`이 사라졌는가
- 헤더에 종 아이콘이 없는가

## 하지 말 것

- **`/home`을 피드로 바꾸지 마라.** 그건 G-1이고 다음 구간이다. 지금은 대시보드 그대로 둔다
- **`/care`를 채우지 마라.** 지도·재진·예약은 G-3이다. 빈 껍데기까지만
- `styles.css`를 크게 손대지 마라 — 탭이 다섯이라 개수는 안 바뀐다
- 새 라우트를 이 목록 밖으로 더하지 마라

## 끝났다고 판단하는 기준

1. `src/App.tsx`의 라우트가 `30-feature-spec.md` §라우트 인벤토리와 맞는다 — **인벤토리도 함께 고친다**
2. 다섯 탭이 전부 살아 있는 화면을 연다
3. 리다이렉트 3개가 돈다
4. `/me/payment`가 라우트·화면·링크 어디에도 없다
5. `npm run test:run` 통과. **탭 경로를 참조하는 테스트가 있으면 함께 고친다**
6. 브라우저로 다섯 탭을 눌러 확인했다
